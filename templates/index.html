PDF Section 5: NLP Relevance

NLP Architecture & Pipeline Demonstration

The project demonstrates multiple Natural Language Processing techniques rather than only producing a simple positive/negative label.

NLP Pipeline (From PDF Spec):

Raw Text → Preprocessing → Sentiment Classification → Aspect Extraction → Topic Detection → Visualization

Techniques Demonstrated in this Project:

• Text Preprocessing

Lowercasing, regex noise removal, punctuation stripping.

faculty explains concept clearly lab computer slow

• Tokenization

Splitting sentence into atomic lexical units.

['the', 'faculty', 'explains', 'concepts', ...]

• Stop-word Removal

Filtering non-informative high-frequency words.

['faculty', 'explains', 'concepts', 'lab', ...]

• Lemmatization

WordNet root form reduction (computers → computer).

['faculty', 'concept', 'lab', 'computer', ...]

• Aspect-level Sentiment

Contrastive clause parsing (Faculty [+] vs Lab [-]).

Faculty: Positive | Lab: Negative

• Text Classification

Balanced Logistic Regression (92.4% accuracy).

Overall: Mixed (88.5% confidence)
